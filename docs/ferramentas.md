# Ferramentas

JUCESP: Download de Documento expõe 1 ferramenta (todas somente leitura).

### 1. `jucesp_documento_consultar`
**Input**: `login_cpf` (opcional), `login_senha` (opcional), `pkcs12_cert` (opcional), `pkcs12_pass` (opcional), `nire`, `registro`

Baixa um documento arquivado de uma empresa na JUCESP a partir do NIRE e do número de registro.

## Prompts de exemplo

```
Baixar documento arquivado na JUCESP
```
